# Linnet starter

Summarize speech-activity intervals from a precomputed frame-level envelope.

Open the extracted folder in VS Code. With Blyx 0.2.1 and its host toolchain installed, choose **Terminal → Run Task → Run Linnet** or run the following command in this directory.

```sh
blyxc native-run main.blyx
```

Expected output

```text
10
70
2
40
```

The vendor directory contains the framework source for 0.1.1 and its license texts. [Read the API guide](https://www.blyx-lang.space/packages/linnet) · [View the release](https://github.com/Rahulchaube1/blyx-linnet/releases/tag/v0.1.1)
