# Blyx Linnet

Summarize speech-activity intervals from a precomputed frame-level envelope.

This extension includes the Blyx Linnet 0.1.1 source, a runnable example and completions for its public functions. It uses the Blyx Language extension for syntax highlighting and execution.

## Run in the editor

1. Open an empty file named `linnet-demo.blyx`.
2. Type `blyx-linnet-demo` and select **Linnet — runnable example**. You can also use **Snippets: Fill File with Snippet**.
3. Choose **Blyx: Run File** from the command palette. Change an argument near the end of `fn main()` to try another input.

Expected output

```text
10
70
2
40
```

## Use Linnet in a project

Extract the starter into a new folder. It contains `main.blyx`, the licensed framework source in `vendor/linnet`, and a VS Code task. With the Blyx 0.2.1 compiler and host toolchain installed, run `blyxc native-run main.blyx` from that folder. Type `blyx-linnet-` in a Blyx file to see the framework completions. [Download the starter ZIP](https://github.com/Rahulchaube1/blyxxxx/releases/download/framework-editors-v0.1.0/blyx-linnet-starter-0.1.0.zip)
